The live chronicle is maintained in [SJTU-TES/gn-chronicle](https://github.com/SJTU-TES/gn-chronicle)
and published at <https://sjtu-tes.github.io/gn-chronicle/>.

The small star in the personal homepage footer links directly to that site.
The old `/chronicle/` URL redirects to the organization site, preserving query
parameters and timeline anchors when JavaScript is enabled.

Edit `content/chronicle.json` in the organization repository to update the story.
The entrance passcode remains `202304`; it is a decorative gate on a public
website, not organization authentication or encryption.

The former `_data/chronicle.yml`, `assets/chronicle/` and `assets/js/chronicle.js`
are retained as a historical source snapshot. The redirect page does not load
them. Updates should be made in the organization repository.
